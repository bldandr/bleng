# Bleng

Интерпретатор собственного языка программирования **"bleng"**, написанный на Free Pascal. Создан с упором на простой, чистый синтаксис и легкую работу с графикой без лишней загруженности языка.

## Возможности

- **Базовые типы и структуры:** `int`, `real`, `char`, `bool`, `string`, а также массивы(одномерные + двумерные).
- **Логика:** функции, параметры по значению и по ссылке (`var`), циклы (`for`, `while`), ветвления (`if/else`).
- **Графика и ввод:** встроенные комманды на базе **Raylib** (окна, рендеринг примитивов, клавиатура, мышь).

## Клонирование и сборка

Проект использует подмодули (Raylib), поэтому клонировать нужно рекурсивно:

```bash
git clone --recurse-submodules https://github.com/bldandr/bleng.git
cd bleng
```

**Сборка интерпретатора:**
```Bash
fpc main.pas
```

**Запуск примеров**
```Bash
./main examples/bfs.b
```

**В папке examples/ лежат готовые демонстрационные программы:**
    quicksort.b - сортировка массива.
    bfs.b - волновой алгоритм поиска пути.
    rabbit.b - игра «Кролик».
